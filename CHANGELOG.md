# Changelog

All notable changes to Usage Tracker Overlay are documented here.

## [1.0.0] - 2026-08-30

### Added

- Six live usage readouts: Ring, Charge, Arc Reactor, Columns, Line, and Semi Circle.
- Clear, Frosted, Solid, and Neon card themes with live opacity and layout controls.
- Claude and Codex usage tracking, Claude sign-in and session-key capture, and Claude extra-credit reporting.
- Tray popover, local history dashboard, exports, notifications, pace indicators, global shortcuts, and runtime automation controls.
- Secure Windows credential storage, public-repository CI, dependency auditing, and full-history secret scanning.

### Changed

- Rebuilt Settings and History as accessible, keyboard-friendly surfaces.
- Usage readout changes repaint immediately from cached provider data instead of waiting for the next poll.
- Refined overlay geometry, provider bubbles, edge-tab tuck behavior, and Windows-native clipping.

## [0.1.2] - 2026-08-01

- Preserved the classic Settings experience before theme controls were introduced.
- Added configurable overlay placement, layout, scale, startup behavior, and circular usage meters.
