# Tray Popover and Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an interactive tray popover that can detach into a persistent overlay, native refresh/settings/quit actions, resilient status banners, and fourteen fully selectable locales.

**Architecture:** Create `codex/feature-popover-i18n` after merging both `codex/feature-react-rendering-foundation` and `codex/feature-display-system`. Rust owns tray events and popover/detached native-window geometry; React reuses the display system and a small internal typed translation catalog, with English fallback and no network-loaded locale assets.

**Tech Stack:** React 19, TypeScript, Intl, Vitest/Testing Library/vitest-axe, Tauri 2, Rust

```rust
#[tauri::command]
fn resize_popover(app: tauri::AppHandle, width: f64, height: f64) -> Result<(), String> {
 let width = width.clamp(240.0, 480.0); let height = height.clamp(120.0, 640.0);

}
```
